# CHANGELOG

This changelog follows the [Keep a Changelog](https://keepachangelog.com/zh-TW/1.1.0/) format to track version updates.

## [2.1.0] - 2026-07-04

### Added

- 新增可直接點擊 Markdown 目錄樹中的檔案或資料夾來加入隱藏清單，行為與搜尋輸入隱藏共用同一套排除邏輯與標籤管理
- 點擊資料夾時會隱藏該資料夾與底下所有子項目；點擊檔案時只會隱藏該檔案，讓排除操作更快速直覺
- 新增隱藏項目清單收折功能，當隱藏標籤超過 6 個時會先收折並顯示剩餘數量，避免清單過長影響頁面瀏覽

### Changed

- 優化隱藏項目搜尋推薦清單，已加入隱藏清單的項目不會再次出現在推薦中；若隱藏的是資料夾，該資料夾底下的子資料夾與檔案也會一併從推薦結果排除
- 預設快速隱藏項目啟用後，符合該名稱的項目與其子項目也會從搜尋推薦清單中排除，避免重複推薦已隱藏內容
- 調整搜尋推薦清單的滾動條樣式為灰白色系，維持深色介面一致性並提升長清單瀏覽質感
- 優化大量檔案目錄樹的輸出渲染，改以單一 Markdown 文字節點呈現完整內容，降低大量互動節點造成的頁面卡頓，同時保留點擊隱藏項目的操作
- 改善排除選項建立、搜尋推薦、檔案篩選與目錄樹 Markdown 產生流程，減少大量路徑資料下的重複計算與排序成本
- 下載圖片用的截圖 DOM 改為按下下載圖片時才建立，避免大型目錄樹在平常瀏覽時同步渲染隱藏截圖內容

### Fixed

- 修正隱藏資料夾中唯一檔案時，父資料夾會因為沒有剩餘子檔而一併從目錄樹消失的問題；現在未被明確隱藏的空資料夾會保留在輸出中
- 修正大量檔案效能優化後，目錄樹項目 hover 時缺少移除提示效果的問題；現在以單行 highlight overlay 保留原本的互動回饋
- 修正下載圖片時可能產生空白或內容偏移的問題，截圖輸出會使用實際節點尺寸並保持內容置中

## [2.0.1] - 2026-05-30

### Added

- 新增以完整路徑為基礎的自訂排除選項，搜尋結果會同時顯示檔案／資料夾名稱與所在路徑，方便辨識同名項目
- 新增 `.venv` 為預設可快速切換的排除項目
- 將 `js-yaml` 納入正式相依套件，確保 YAML 檔案解析在正式環境中可正常使用

### Changed

- 改善首頁標題、容器、拖放區與輸出面板的響應式排版，降低寬螢幕與手機版內容溢出或擠壓的情況
- 將拖放區操作提示改為多行顯示，並同步更新繁體中文、英文與日文文案，提升操作說明可讀性
- 調整輸出面板操作按鈕，補上無障礙標籤與提示文字，並在窄螢幕改為保留圖示以避免工具列擁擠
- 調整目錄樹輸出區的字距、最小高度與水平捲動行為，讓輸出內容在不同裝置上更穩定易讀
- 自訂排除邏輯改為精準比對選取的單一檔案或整個資料夾路徑，避免輸入同名檔案／資料夾時誤排除其他位置的項目
- 調整排除控制列排版，預設排除項目會固定顯示於搜尋欄下一行，不再與搜尋欄同行
- 手動加入的排除標籤改為接續顯示在預設排除項目後方，讓所有排除標籤集中於同一列
- 下載 Markdown 時改以 `bash` fenced code block 包住目錄樹內容，讓輸出檔案可直接貼入 Markdown 文件並保留格式
- 調整資料夾拖曳讀取流程，完整讀取多批次目錄項目並在讀取失敗時顯示不支援輸入提示
- 預設語言固定為英文，僅在網址 `lng` 參數有效時切換至指定語系

### Removed

- 移除檔案／資料夾容量顯示切換功能，輸出的目錄樹不再附加容量資訊

## [2.0.0] - 2025-12-20

### Added

- 將原本分離的 **folder / JSON / YAML** 三種模式整合為單一輸入模式，並可自動偵測使用者輸入的檔案類型
- 新增操作方式支援：
  - **左鍵點擊**：選擇整個資料夾
  - **右鍵點擊**：選擇單一檔案
- 新增 **「清除」按鈕**，可一鍵清空目前產出的樹狀結果與輸出內容，提升使用流程順暢度
- 新增 ScrambledText 文字動畫效果，用於重點說明與提示文字顯示。

### Changed

- 將專案建置工具由 **Create React App（CRA）** 全面遷移至 **Vite**，大幅提升開發啟動速度與建置效率
- 重構 `Home` 頁面結構，將可重複使用的 UI 拆分為獨立元件，降低單一元件複雜度
  - 共用邏輯與輔助函式集中移至 `utils`，強化職責分離並提升整體可維護性
  - 改善整體程式碼可讀性，調整檔案與模組責任邊界，使後續擴充與除錯更容易
- 語言切換改為「英文預設 + 參數覆寫」策略：
  - **預設語言固定為英文（en）**，不再依瀏覽器語言自動切換。
  - 支援透過網址參數強制指定語言：`/?lng=...`
    - `/?lng=zh-Hant` → 繁體中文
    - `/?lng=en` → 英文
    - `/?lng=ja` → 日文
- 若網址 `lng` 參數無法匹配以上三種語言，則 **一律回落為英文（en）**，確保可用性與一致性。

### Removed

- 移除所有隱藏的 **網頁彩蛋（Console Easter Egg）** 相關邏輯與程式碼
- 移除 **網站計數器（Visit Counter）** 元件及其對外 API 呼叫，確保專案為純前端、零追蹤設計
- 移除 **GooeyNav** 導航列的 UI 動畫效果與相關元件／樣式，簡化介面與依賴。
- 移除頁面底部（或原本位置）的「語言選擇按鈕」與相關切換 UI。
- 移除非必要語系資源與設定，語言僅保留：
  - 繁體中文（zh-Hant）
  - 英文（en）
  - 日文（ja）
